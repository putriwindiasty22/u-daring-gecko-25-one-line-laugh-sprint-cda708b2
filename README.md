**One-Line Laugh Sprint** — a single original funny line about everyday life. `main.ts` (Node 22, no network, no dependencies) writes the line to `/output/entry.txt` (falling back to `./output/entry.txt` when run locally).

The joke plays on a habit everyone recognises: setting a row of alarms to wake up early, then snoozing every one of them. The setup reads like a confession of failure; the punchline reframes it as a technicality — each snooze still counts as waking up, so the plan worked after all.

## Run it

```sh
node main.ts
```

Then read `output/entry.txt` (or `/output/entry.txt` in the grading sandbox).
